# Patchwork — CS3014 Applied HCI, Assignment 4

**A second life starts here.** Patchwork is a resource-reuse app: record what you own, and it helps you make, repair and improve things with it.

| Folder | What it is |
|---|---|
| `*.png` (root) | The 29 Figma app screens plus the submission pages (cover, declarations, inventory, traceability) |
| [`figma-plugin/`](figma-plugin/) | A Figma plugin that turns the 29 screens into a fully clickable prototype. See its README. |
| [`patchwork-app/`](patchwork-app/) | A working web app (React + Node + SQLite) built from the same design. See its README. |

## Quick start (web app)

```bash
cd patchwork-app
npm install
npm run dev
```

Open http://localhost:5173. Demo login: `fatima@example.com` / `patchwork123`.
